# IUE - Parcial Operador Logístico

Aplicación Java Swing del parcial.

## Funciones
- Agregar envío
- Retirar envío
- Listar envíos
- Cálculo polimórfico de tarifa

## Tarifas
- Terrestre: 1500 por Km + 2000 por Kg
- Aéreo: 5000 por Km + 4000 por Kg
- Marítimo: 800 por Km + 1000 por Kg

## Ejecutar
Abrir la carpeta en Visual Studio Code, abrir `src/App.java` y seleccionar Run Java.
